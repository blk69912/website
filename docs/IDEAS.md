# website リポジトリ: スターを集めるためのアイディア集

作成日: 2026-11-05 / 対象: https://github.com/blk69912/website (現状 README のみ)

## 0. スターが付くサイトの共通法則

1. 開いた瞬間に価値が分かる(ライブデモ + README 冒頭の GIF)
2. 繰り返し使う実用ツールか、1回見て人に教えたくなる体験のどちらか
3. 「今」話題のテーマに乗っている(2026年なら AI エージェント / MCP / Agent Skills)
4. 自分でも作れそうに見えて、作るのは面倒(=代わりに使う、=スター)
5. one-click deploy(Vercel ボタン)・MIT ライセンス・good first issue で参加障壁が低い

## 1. アイディア一覧(おすすめ順)

### ★1 Agent-Ready Checker — 「このサイトは AI エージェントに優しいか」診断ツール
- URL を入れると llms.txt / robots.txt の AI クローラ対応 / 構造化データ / Markdown 変換品質 / 認証不要 GET API の有無などを採点
- スコアバッジ(shields.io 形式)を README に貼れるようにする → バッジ経由で自然拡散
- 診断結果から llms.txt / sitemap を自動生成してダウンロード
- 強み: 需要が急増中、競合が少ない、technocore-chat の知見(webfetch しかできないエージェント)をそのまま活かせる

### ★2 Agent Dev Tools — エージェント開発者向けブラウザ完結ツール集
- it-tools(2万スター超)のエージェント特化版。全部クライアントサイド、送信なし
- 候補: トークンカウンタ、プロンプト diff、JSONL トレースビューア、ツール呼び出しタイムライン可視化、MCP マニフェスト検証、Skill フロントマター lint、コスト見積もり
- 1ツール1ページで検索流入を取りやすい。追加 PR を募りやすい

### ★3 How Agents Work — インタラクティブ解説サイト
- 「DNS の仕組み」「Git の内部」系の対話型解説はスターが集まりやすい定番
- ツール呼び出しループ、コンテキストウィンドウ、サンドボックス、MCP の流れをスクロール連動アニメーションで解説
- 日本語 + 英語の二言語で出すと Zenn/Qiita と Hacker News の両方で拡散できる

### ★4 Skills / MCP サーバー ディレクトリ
- GitHub API で自動収集し、タグ検索・人気順・最終更新で並べる「生きた awesome-list」
- 投稿は PR で1行追加するだけにして、コントリビュータを増やす(コントリビュータは高確率でスターする)

### ★5 Webfetch-Only Web — GET リクエストだけで完結するサービス群
- technocore-chat の思想を拡張。サンドボックス内エージェントが使える「URL だけの」メモ、カウンタ、短縮、ペーストビン、KV
- ニッチだが独自性が極めて高く、エージェント界隈で語られやすい

### ★6 Agent-Aware ポートフォリオ / ブログテンプレート
- テンプレート系は安定してスターが付く
- 差別化: llms.txt、JSON Résumé、OGP 自動生成、Vercel ボタン、Lighthouse 100 を標準装備

### ★7 遊べる系(拡散用)
- 「HTTP ステータスコード当てクイズ」「ターミナルコマンド タイピングゲーム」「プロンプトインジェクション防御ゲーム」
- SNS でバズる → スターが一気に伸びる。★1や★2への導線として置くのが効果的

## 2. 推奨する組み合わせ

★1(診断ツール)を看板に、★2(ツール集)を同じサイトに同居させる。
- 診断ツールは「バッジ」で拡散し、ツール集は「毎日使う理由」で再訪とスターを稼ぐ
- 技術: Next.js(App Router)+ Tailwind、全処理クライアントサイド、Vercel にデプロイ
- README: 冒頭に 10 秒 GIF、ライブ URL、Deploy ボタン、バッジ

## 4. 失敗パターン(避けること)

- README が「# website」のまま(今の状態)。説明・スクショ・デモがないリポジトリはスターされない
- バックエンド必須で自分でホストできない(フォークしても動かない)
- 汎用的すぎるツール集(既存の it-tools に勝てない)。必ず「エージェント開発者向け」に絞る
- 日本語のみ、または英語のみ。両方用意する
